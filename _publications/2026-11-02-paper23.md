Large language models (LLMs) can be used to generate parameterized layouts, but their output does not always conform to the syntax and constraints of a layout description language, and such issues are not always corrected in a principled way.

This paper presents SGLayout, a schema-guided closed-loop refinement framework for LLM-driven parameterized layout generation. A schema is used to guide generation toward valid structures, and a closed-loop refinement process feeds validation results back to the LLM so that it can revise its output over successive iterations.
